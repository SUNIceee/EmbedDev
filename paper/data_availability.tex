\section*{Data Availability}
We have prepared a replication package containing an English-language implementation of \textsc{EmbedDev}, prompt templates, task specifications and API contracts, saved candidate artifacts and evaluation records, and scripts for reconstructing the RQ1--RQ4 tables and the six-task RQ3 line chart.
The package documents source versions, input and prompt translations, metric definitions, and artifact provenance.
Offline result reconstruction is separated from new model-based generation, which requires the reader's own model-service access and toolchain.
The README identifies evidence that is not included in the archive and distinguishes locally verified records from author-reported results.
